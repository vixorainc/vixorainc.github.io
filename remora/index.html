FEATURES

Focused on Android TV and Google TV.

Remora's current development baseline is intentionally specific: compatible Android TV / Google TV Remote Service v2 devices first, rather than claiming support for every TV platform.

📡 Local discovery

Discover compatible Android TV and Google TV devices available on the same local network.

🔐 Secure pairing

Pair using supported TV remote-service flows, with TLS client identity protected using Android Keystore facilities.

🎛 Remote control

Send supported control commands directly between your phone and paired TV on the local network.

☁️ No Vixora backend

The current architecture does not route ordinary remote commands through a Vixora cloud service.

🚫 No ads or account

The current development baseline has no advertising, Vixora account, subscription or analytics service.

🧪 Production readiness

Compatibility, reliability and release behavior are being tested before public distribution.

IN DEVELOPMENT
