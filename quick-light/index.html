FEATURES

Useful lighting without the clutter.

Quick Light keeps the interface simple while covering the lighting modes people are most likely to need quickly.

🔦 Torch mode

Turn the device LED torch on or off quickly from a focused control screen.

💡 Brightness mode

Use the display as a bright, broad light source with screen-brightness control.

🆘 SOS mode

Run a repeating visible SOS-style flash pattern for attention. It does not contact emergency services.

🌙 Keep-awake support

Light use can keep the display active when needed so the screen does not immediately sleep.

📴 Offline core

The core flashlight, brightness and SOS modes do not depend on an internet connection.

⚡ Lightweight design

Built around quick access, clear mode switching and minimal setup.
